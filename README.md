# Student System

A simple C# console application for practicing menu-driven student record management.

## Features

- Add a student's name.
- List the names currently in the program.
- Remove a student by name.
- Handle menu choices and show a message for invalid selections.

## Technology

- C#
- .NET Framework 4.7.2
- Console application

## Run

Open `Öğrenci Sistemi.sln` in Visual Studio 2022, restore or retarget the .NET Framework 4.7.2 Developer Pack if prompted, then build and run the console project.

## Scope

Student names are stored in an in-memory list and are cleared when the program closes. This project is a learning demo; it does not use a database or persistent storage.
